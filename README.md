# Past-to-PNG
✨ Key Specializations & Features:

🔒 100% Offline & Private: Operates entirely on your local machine without sending data, logs, or images to any external cloud service or third-party server.

⚡ Standalone EXE: Fully compiled into a ready-to-run Windows executable—no Python installation or extra dependencies required to run.

🖱️ Instant Capture: Press Ctrl + V anywhere on the app window or click the interface to instantly grab and save clipboard graphics (ImageGrab.grabclipboard()).

📁 Smart Automated Organization: Automatically sorts saved .png files into structured directories (Pictures/Pasted Images/DD-MM-YYYY/) with built-in duplicate prevention counters.

🎨 Sleek Dark-Mode GUI: Custom borderless window design featuring smooth drag-and-drop navigation, custom Alt-Tab window integration, and rich animated toast notifications

🧹 Clipboard Cleanup: Automatically clears the system clipboard after a successful write operation to keep your workflow clean.


🛠️ Tech Stack & Build Environment:

Language/Core: Python, Tkinter, Pillow (PIL)

Packaging: PyInstaller (compiled into a standalone .exe)   

System Integration: Windows Win32 API (ctypes) for window handling and clipboard management


🚀 How to Use

Download the latest standalone Past-to-Img-Gemini.exe from the Releases page.

Double-click the .exe to launch the application.Copy any image or screenshot to your Windows clipboard (Print Screen, right-click copy, etc.).   

Press Ctrl + V or click the center download arrow inside the app window.   

Your image is instantly saved locally, and a toast notification confirms the file path. 

Click the bottom path label to instantly open the destination folder in Windows Explorer.
